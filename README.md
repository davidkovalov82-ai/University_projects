## Лабораторно упражнение 3: програми с разклонения

Папка: [`lab3-practice/`](lab3-practice/).

Упражнението следва материала **`Lab3a_2023.pdf`**, тема №4: „Базови управляващи структури. Създаване на програми с разклонения“. Основните теми са `if`, `else if`, вложени условия, логически оператори и `switch`.

Номерата по-долу са от раздела **„Задачи за самостоятелна работа“** в PDF, а не от имената на файловете. „Няма качено решение“ описва съдържанието на репозитория.

## Компилиране и стартиране

Необходими са C++17 компилатор и, за основния проект, CMake 3.16 или по-нова версия.

### Основен проект: задача 5

От основната папка на репозитория:

```bash
cmake -S lab3-practice -B lab3-practice/build
cmake --build lab3-practice/build
./lab3-practice/build/lab3-practice
```

В текущия [CMakeLists.txt](lab3-practice/CMakeLists.txt) активната цел компилира само **`biggest.cpp`**.

Алтернативно:

```bash
cd lab3-practice
bash run.sh
```

### Отделна задача

Всеки завършен `.cpp` файл съдържа собствена функция `main` и се компилира отделно. Например, от основната папка на репозитория:

```bash
mkdir -p lab3-practice/build
g++ -std=c++17 -Wall -Wextra -pedantic \
  lab3-practice/code/hardest-problem.cpp \
  -o lab3-practice/build/quadratic
./lab3-practice/build/quadratic
```

За друга задача заменете пътя до изходния файл и името на изпълнимия файл. Не компилирайте всички `.cpp` файлове в един изпълним файл.
